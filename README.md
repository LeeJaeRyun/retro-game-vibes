# 🏐 에코노배 피카츄 배구 대회 ⚡

추억의 클래식 게임, '피카츄 배구'를 현대적인 웹 기술로 재해석한 프로젝트입니다. 의찬과 준서의 치열한 스파이크 대결을 지금 바로 경험해 보세요!

## 🎮 주요 기능

- **싱글 모드**: 인공지능(AI) 피카츄를 상대로 실력을 연마하세요.
- **멀티 모드**: 한 컴퓨터에서 친구와 함께 1대1 대결을 즐기세요.
- **실시간 감정 시스템**: 점수 차이에 따라 캐릭터의 표정이 실시간으로 변화합니다. (지고 있으면 웁니다 😢)
- **박진감 넘치는 이펙트**: 전방향 스파이크 기능과 화려한 불꽃 파티클 효과.
- **다이내믹 오디오**: 상황에 따라 변하는 배경음악(Super Mario 64)과 좌절 BGM 시스템.

## ⌨️ 조작 방법

### Player 1 (의찬)
- **이동**: `A`, `D`
- **점프**: `W`
- **스파이크**: `Space`

### Player 2 (준서)
- **이동**: `←`, `→` (방향키)
- **점프**: `↑` (방향키)
- **스파이크**: `K`

---

## 🛠️ 기술 스택

- **Framework**: React 18
- **Language**: TypeScript
- **Bundler**: Vite
- **Rendering**: HTML5 Canvas API (High-Fidelity Rendering)
- **Styling**: Vanilla CSS
